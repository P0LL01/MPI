This program is an MPI-based parallel application designed to process a user-defined vector of integers across multiple processors. The program begins by collecting input from the user on process 0, allocating and distributing the vector evenly among all available MPI processes. Each process receives a sub-vector and performs several computations locally before collaborating with the rest of the system through MPI communication routines. The program calculates global statistics such as the average, minimum, and maximum values of the vector, using local computations combined through MPI_Reduce. It then computes the global variance and performs normalization, where each element is transformed into a percentage scale based on the global minimum and maximum. The program also determines the position of the maximum normalized value using MPI_MAXLOC to efficiently identify both the value and its index. Additionally, it computes the prefix sums of the vector in parallel using MPI_Scan and MPI_Gather, producing a final cumulative-sum vector on the root process. After displaying all computed results, the program offers a simple menu that allows the user to repeat the entire process or exit. Memory is dynamically allocated and freed throughout, ensuring correct operation across multiple iterations.
